# 功能盘点与路线图

对照主流群管 / 抽奖机器人（Rose、GroupHelp、Combot、Shieldy、Group Butler、方丈、nmbot、各类抽奖助手）。

## v1.7 已完成
- 话题群支持（定时消息 / 广告 / 抽奖 / 欢迎语可选话题，提示回到原话题）
- 签到积分、发言积分、活跃榜、积分榜、自动发榜
- 邀请统计（专属链接、通过验证才算、邀请榜、邀请奖励）
- 举报阈值自动禁言、/votekick 投票踢人
- 欢迎语带图片 / 动图 / 视频
- 新人 N 小时只能发文字
- /zombies 清理已注销账号
- 抽奖：多奖项、周期抽奖、置顶、群内直接参与、积分 / 邀请门槛、公开种子可验证
- 自动回复：完全一致 / 开头 / 正则、多条随机、自动删除
- /info 成员资料
- 数据库每天自动备份、邀请链接定时轮换
- AI 看图识别图片广告；NFKC 归一化防花体字绕过
- 私聊按钮面板重做 + 指定谁能在 Telegram 里管理
- 面板「从 Telegram 获取」（动态表情、格式、媒体）

## 还可以做的
1. ~~群管理员网页面板（Mini App）~~ v1.8 已完成。
2. **积分商城**：积分兑换卡密 / 头衔（setChatAdministratorCustomTitle 需要先提为管理员，或用机器人记录的「称号」）。
3. **入群问答题**：自定义问题（例如「本群是做什么的」）代替验证码，过滤走错门的人。
4. **消息定时自毁**：指定话题里的消息 N 小时后自动删除（资源分享群常用）。
5. **多语言**：英文界面和提示，方便海外群。

## 已知但没改的小问题
- 夜间模式开启时如果读取群默认权限失败，结束时会恢复成「全部允许」。
- 动态表情只有在机器人拥有 Fragment 收藏用户名时才能真正显示，否则自动降级为普通 emoji。
- `/call` 插件（call_owner）没有新成员限制，理论上能用小号凑人数。
